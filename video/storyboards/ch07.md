# Ch 07 · Convention Over Configuration: storyboard

**Narrator:** AI voice (MiniMax Speech 2.6 HD, English_magnetic_voiced_man).
**Logline:** The same agent writes senior-grade code in a consistent code base and a mess in an inconsistent one. Conventions are implicit context and long-term memory; the instruction file, skills and hooks make them explicit.
**Inks:** the series set (federal, orange, yellow). Overprints: yellow highlighter passes over files and tabs, orange over navy on the hot rows, green test corners (federal + yellow).
**Motif:** matching card triples (handler, schema, test: navy, gold, green). They line up in the tidy project, scatter in the messy one, and come back as a tidy town at the end.
